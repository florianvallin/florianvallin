  1. Dans votre version HTML locale, cliquez sur Exporter une sauvegarde JSON.

  3. Dans Données & confidentialité, importez votre fichier : vous devrez confirmer le remplacement des tableaux existants.

Une page ouverte depuis un fichier, un site web ou un autre navigateur n'accède pas automatiquement aux données des autres environnements. Le transfert requiert cet import manuel.

Vie privée

Cette application autonome fonctionne localement. Elle n'utilise ni compte, ni publicité, ni serveur de synchronisation, ni traceur, ni ressource externe. Les données restent sur cet appareil et peuvent être supprimées avec le stockage du navigateur. Les liens ajoutés dans vos tâches peuvent naturellement ouvrir des sites tiers.

Le fichier exporté n'est pas chiffré : protégez-le s'il contient des informations personnelles. Le stockage du navigateur peut être effacé automatiquement ou manuellement : les exports réguliers restent importants.

Effacer les données de cet environnement

Supprime tous vos tableaux locaux, archives, idées, historiques et règles sur cette origine. Les sauvegardes JSON déjà téléchargées ne sont pas effacées.

Déplacez les cartes à la souris ou au clavier : flèches pour naviguer parmi les cartes, Alt + flèches pour les déplacer, Entrée pour ouvrir la fiche. Dans le menu « … » d’une colonne, définissez une limite WIP et des règles de passage. Dans chaque fiche, gérez les blocages et les tâches préalables. Les poignées des colonnes servent à les réorganiser. Sur mobile et au clavier, utilisez le menu « … » des colonnes et les contrôles dans les fiches de tâches.
