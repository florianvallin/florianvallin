?Mode d’emploi⌄
  1. Importez une image ou un PDF (ou collez une capture d’écran).
  2. Choisissez les langues ; réglez si besoin l’image ou une zone, puis lancez « Reconnaître ».
  3. Vérifiez et corrigez la transcription avant de l’exporter. Pour plusieurs pages, utilisez « Traiter le lot ».

Astuce : Ctrl + S enregistre le projet localement ; Alt + 1 cible l’import et Alt + 2 le texte.

♧Confidentialité et limites⌄

La reconnaissance est exécutée dans le navigateur : l’outil n’envoie pas intentionnellement vos documents à un serveur pour les analyser. Des ressources techniques (moteur, modèles de langues, bibliothèques PDF/Word et parfois police) sont téléchargées à la demande auprès de services externes : une connexion Internet est nécessaire au premier usage et potentiellement après vidage du cache.

Le projet n’est sauvegardé sur cet appareil que si vous l’enregistrez ; vous pouvez ensuite le supprimer. Les préférences de thème et de langue sont mémorisées séparément. Sur un appareil partagé, pensez à effacer le projet et les données du site.

La reconnaissance peut se tromper, notamment pour l’écriture manuscrite, les colonnes complexes, les tableaux, les caractères anciens et les pages dégradées. Vérifiez toujours les passages importants.
