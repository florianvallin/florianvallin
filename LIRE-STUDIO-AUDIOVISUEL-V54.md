# Philosophal V54 · Studio audiovisuel V11

Le Studio audiovisuel se trouve dans « Outils > Mes outils professionnels », après identification.

Chemins :
- `/outils/studio-audiovisuel/` : accueil privé et application intégrée.
- `/outils/studio-audiovisuel/editeur.html` : moteur autonome V11, avec contrôle d’accès côté navigateur.

Les pages publiques ne changent pas. Les enregistrements, projets et modèles Whisper ne sont pas inclus dans le ZIP : ils restent dans le navigateur utilisé.

Attention : GitHub Pages héberge les fichiers HTML publiquement. Ce contrôle d’accès côté navigateur n’est pas une barrière serveur et ne protège pas le code source des outils. Les données audiovisuelles, elles, ne sont pas ajoutées au dépôt. Pour un code réellement privé, il faudrait déployer derrière une authentification serveur ou chiffrer le contenu applicatif comme les archives propriétaires existantes.

Autoriser le microphone, la caméra ou le partage d’écran à la demande dans le navigateur. Le HTTPS est requis pour ces API.
